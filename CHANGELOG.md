# Changes

## Version 2, 2026-11-23

Centring keys, as on Voron's own frame-mounted parts. Each leg has a rib 5.8 mm wide and 1 mm
high that sits in the extrusion's slot opening, running the length of the leg and broken only
around the screws. The outline, screw positions and hardware have not changed, so braces
printed from version 1 still fit, without the keys.

## Version 1, 2026-11-22

First release: four side braces, an optional arched front pair and an optional rear pair, the
script that makes them, and STEP versions.
